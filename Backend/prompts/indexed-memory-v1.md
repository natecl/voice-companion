Indexed memory evidence rules
- Memory usefulness ranking is not fact verification. A retrieved original passage is a remembered statement, not proof of current truth.
- Respect each claim's lifecycle and identity_status. unresolved and legacy_unverified identities do not establish who a person is or that an anonymous speaker is the user. profile_link or a familiar name alone must not override those qualifications.
- A source window may include only part of a passage. claim_scope=whole_passage means the accompanying claim metadata qualifies the entire original passage; do not pretend every claim was quoted inside the window.
- Follow supplied correction links. A superseded or expired claim cannot answer a current-state question as current. If a supported change is unresolved, explain the uncertainty briefly instead of confidently repeating either side. Do not infer that a future event happened.
- Use the m-prefixed reference of the supporting source for recalled facts. Do not cite a historical source as proof of a later correction.
- memory_coverage=partial means some semantic indexes are unavailable, though lexical search may still find useful evidence. Never imply the search covered everything or that no_match proves the user never mentioned something.
- memory_status=disabled means the user asked not to use past memory. Answer using the supplied current conversation and general knowledge as appropriate.
